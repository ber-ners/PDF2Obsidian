# 本地 Web 工作台

在项目根目录运行 `npm run dev`，访问 http://127.0.0.1:3000 。

首次访问自动创建配置，进入工作台后在设置中配置 PDF 解析服务和可选 AI 服务。无需配置 Obsidian 或保存路径。结果保存在项目 `output/papers/`，上传文件和任务记录保存在 `.pipeline/desktop-web/`。

支持上传 PDF、URL / arXiv / DOI 导入、PDF 预览、任务进度、重试、正文和阅读材料预览。关闭翻译时依然可以查看解析后的正文。

生产运行：在根目录执行 `npm run build` 后执行 `npm start`。

### PDF 与原文区块联动

完成解析后，点击 PDF 中的蓝色区块框，右侧会切换到“原文”并滚动、高亮对应段落；点击原文或“第 N 页 ↗”可反向定位 PDF。支持翻页、缩放、隐藏区块边框，以及原文中的公式和提取图片。表格优先显示提取的表格图片。

联动使用 MinerU `content_list.json` 的页码和归一化坐标；不需要重新调用翻译服务。已有任务会尝试查找原解析目录；缺少区块文件/坐标时显示提示并保留普通原文预览。“中英对照”支持同样的双向定位，并一起高亮配对的英文和中文；结构不一致的部分按整节联动。阅读材料暂不支持区块联动。HTTP 解析服务需支持 `return_content_list`；官方 ZIP 和本地命令生成的区块文件可直接读取。

PDF.js worker 在开发、构建和启动时从已安装依赖复制到 public，版本与 PDF.js 一致，无需外部 CDN。

中英对照的映射从原文配对关系与 MinerU 坐标生成，不调用翻译 API。对已有任务可直接生效；手工编辑后若配对正文与源文件不一致，会保留编辑内容并提示定位暂不可用。PDF 页眉、页脚、页码等未收录到对照正文的区块不参与匹配。

### 版面类型与阅读样式

原文和中英对照预览保留 MinerU 的正文、标题、图片、表格、图表注释、脚注、页眉、页脚、页码和参考文献类型。标题按层级放大加粗，图片下方的图注居中显示，脚注及页脚使用较浅的小字；正文保持正常字号。图表本体、说明和脚注独立渲染，PDF 点击定位仍绑定原区块。中英内容可逐段配对时，两种语言沿用相同类型；整节回退配对保留原有提示，不把混合内容整节误设为注释。无需重新请求解析/翻译即可应用已有结构化数据。

### 阅读布局与画面移动

拖动 PDF 与输出结果之间的分隔线可调整两栏宽度，比例会自动保存。双击分隔线或聚焦后按回车恢复均分，左右方向键微调。收起任务侧栏后两栏自动扩展，窄窗口自动改为上下排列。PDF 工具栏中的“移动画面”支持按住拖动放大后的页面，关闭后可继续点击区块联动；“适应宽度”恢复自适应缩放。页码输入按回车或离开输入框后跳转，翻页回到页首，缩放和调整栏宽尽量保留当前阅读位置。
