# PDF2obsidian - Obsidian 原生插件

## 快速安装方法

1. 找到你的 Obsidian 知识库目录（Vault）。
2. 进入知识库隐藏配置目录：`<你的Vault路径>/.obsidian/plugins/`。
   > 提示：在 macOS Finder 中按 `Cmd + Shift + .` 可以显示/隐藏以点开头的隐藏文件夹。
3. 将本文件夹 `pdf2obsidian` 整个复制到 `.obsidian/plugins/` 目录下：
   ```text
   <你的Vault路径>/.obsidian/plugins/pdf2obsidian/
   ├── main.js
   ├── manifest.json
   └── styles.css
   ```
4. 打开 Obsidian：
   - 进入 **设置 (Settings)** -> **第三方插件 (Community plugins)**；
   - 点击 **已安装插件** 旁边的 **刷新 (Reload)** 按钮；
   - 找到 **PDF2obsidian** 并将其开启。
5. 开启后：
   - 点击左侧 Ribbon 活动栏上的 **书本图标 (`book-open`)**；
   - 或者按下快捷键 `Cmd + P` 打开命令面板，输入 `打开学术双栏阅读器`，即可唤起双栏文献阅读工作台！
